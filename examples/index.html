BootSideMenu

Change any option to tear the menu down and build it again with the new settings. The configuration is kept in the URL, so a reload comes back to the same one — which is what makes remember testable here.

Things worth trying

  • Open the menu, reload the page with remember on: the state comes back. The storage readout says which of the two stores did it — over file:// a cookie will not work in Chrome, but localStorage does.
  • With pushBody on and the menu open, narrow the window below 480 pixels: the plugin stops pushing, and the body margin has to go back with it.
  • Tab to the toggler: it takes focus, Enter and Space both work, and Escape closes the menu.
  • Press the button inside the menu. Its handler is attached before the plugin runs, so the log entry proves initialization left the original nodes alone.
  • Rebuild a few times and watch the log: a callback appearing twice would mean destroy() left a handler behind.
